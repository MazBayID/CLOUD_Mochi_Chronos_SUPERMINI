# Chronos audio fix bundle

Source repository reviewed:
MazBayID/CLOUD_Mochi_Chronos_SUPERMINI

Files intentionally NOT changed:
- include/dirgamochi_config.h (pin mapping is preserved)
- assets/audio/mochi_voices.zip (user-tuned WAVs preserved)
- assets/faces/* (user-tuned animations preserved)
- generated/* (regenerated by the existing asset tool)
- tools/generate_assets.py (no runtime bug requires changing the user's assets)

Included:
1. src/audio_engine.cpp — complete replacement.
2. patches/02_buzzer_engine.patch — small ownership-transition fix.
3. patches/03_sprite_face_engine.patch — clarifies/locks primary-blink audio behavior.
4. patches/04_main.patch — process I2S before BuzzerEngine completion polling.

IMPORTANT:
The three patch files are unified diffs against the current main branch. They are
provided rather than replacing entire source files so that unrelated user code
is not overwritten.

The main runtime fix is audio_engine.cpp: the old implementation generated
mono I2S data as stereo pairs and could advance the ADPCM decoder even when
i2s_write() accepted fewer bytes than requested. The replacement keeps pending
PCM until the I2S driver accepts it.
